How the chatbot answers a message

Where a customer's message travels, which of it the code answers on its own, and the four places the AI is actually called.

The bot is not a wrapper around a model. It is a pipeline of ordered branches that answer from the seller's own data wherever they can, and call the model only where reading a sentence is genuinely required. That ordering is the design: it is what keeps prices, stock and delivery fees exact, and what keeps the token bill survivable on a free tier.

The four AI calls

Two models are configured. Classification is mechanical and runs constantly, so it goes to the small one; answering questions about a catalogue is why a capable model is configured at all.

call runs model what it does
storefront_intent every message fast reads a sentence into one of 20 intents, plus the language
detect_chat_language every message fast names the language when the script alone is ambiguous
translate_chat_message most replies fast turns a reply the code wrote in English into the customer's language
generate_*_answer when nothing matched full product questions, catalogue questions, comparisons

Across one complete order — browsing, a feature question, a comparison, then seven checkout answers — 28 of 30 model calls go to the small model. The two that do not are the feature answer and the comparison.

How it remembers

The session document carries a rolling window of the last twelve turns. They are sent as real chat messages — the same shape ChatGPT uses — not summarised into a paragraph about the conversation.

Why the pipeline comes first

A model must never be the source of a number. Prices, stock, delivery fees, warranty months and order totals are read from Firestore and put into the reply by code. The model is given those facts and told to quote them exactly; it is never asked to recall them.

The same logic decides ordering. Adding to a cart, choosing a variant, setting a quantity, taking an address and placing the order are all deterministic, because a misread quantity is a wrong parcel and a misread district is a wrong delivery fee. The model reads what the customer meant; the code decides what happens.

When the provider is down, the shop still works. Every AI path has a deterministic answer behind it. Comparisons fall back to a spec table built from stored fields, feature filters read the seller's descriptions directly, and replies arrive in English rather than not at all.

Where the cost goes

Each product added to a prompt costs roughly 86 tokens. The full catalogue is sent on catalogue questions, so the ceiling arrives at about 90 products — beyond that, a single question can exceed the per-minute budget on its own. Two levers exist before that becomes urgent: shortlisting the catalogue to the products a question could plausibly concern, and raising the provider tier.
